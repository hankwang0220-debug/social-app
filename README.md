# 🎡 命運轉盤 App

選擇困難救星！選一個主題（例如：晚餐），按下按鈕轉動轉盤，讓命運幫你決定要吃什麼、喝什麼、做什麼。

## 怎麼使用

直接用瀏覽器打開 `index.html` 就可以用了，不需要安裝任何東西。手機、電腦都能玩。

功能：

- **內建選項庫**：「晚餐」「午餐」「飲料」「假日活動」都內建了滿滿的選項，打開就能直接轉，不用自己想
- **保留／排除**：這一輪不想要的選項，點一下就排除；再點一下就恢復
- **我的組合**：把「保留哪些選項」的設定存成組合，下次一鍵套用直接開轉
- **自訂主題**：也可以新增自己的主題和選項（例如：宵夜、電影）
- **自動記憶**：你的設定會存在瀏覽器裡，下次打開還在

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `index.html` | 網頁的骨架（畫面上有什麼東西） |
| `style.css`  | 外觀樣式（顏色、大小、排版） |
| `app.js`     | 轉盤邏輯（怎麼轉、怎麼選出結果、資料儲存） |

## 一起開發的流程

每次開始做事之前，先拿最新版本：

```
git pull
```

改完程式之後，把改動送上 GitHub：

```
git add .
git commit -m "說明你改了什麼"
git push
```
