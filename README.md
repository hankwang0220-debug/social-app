# 🎲 今天要幹嘛？

一群人出來卻不知道要做什麼？讓隨機幫你們決定！

**線上版（手機電腦都能玩）**：https://hankwang0220-debug.github.io/social-app/

## 模組

| 模組 | 狀態 | 說明 |
|------|------|------|
| 🎡 命運轉盤 | ✅ 可以玩 | 選主題轉轉盤決定吃什麼，可定位找附近店家 |
| 🎲 抽籤器 | 🚧 規劃中 | 誰付錢、誰先開始、隨機分組 |
| 🃏 任務卡 | 🚧 規劃中 | 真心話大冒險、話題卡 |
| 🍱 懶人套餐 | 🚧 規劃中 | 一鍵轉出完整行程 |

## 🎡 命運轉盤

選一個主題（例如：晚餐），按下按鈕轉動轉盤，讓命運幫你決定要吃什麼、喝什麼、做什麼。

功能：

- **內建選項庫**：「晚餐」「午餐」「飲料」「假日活動」都內建了滿滿的選項，打開就能直接轉，不用自己想
- **保留／排除**：這一輪不想要的選項，點一下就排除；再點一下就恢復
- **我的組合**：把「保留哪些選項」的設定存成組合，下次一鍵套用直接開轉
- **自訂主題**：也可以新增自己的主題和選項（例如：宵夜、電影）
- **自動記憶**：你的設定會存在瀏覽器裡，下次打開還在

## 一起開發的流程

每次開始做事之前，先拿最新版本：

```
git pull
```

改完程式之後，把改動送上 GitHub：

```
git add .
git commit -m "說明你改了什麼"
git push
```
